# Agent Notes

## Adding Jokers

When adding a new Joker, ask the developer how **The Portrait** should copy it before implementation.

Confirm at least:
- Whether the copied Joker can be selected by The Portrait.
- How the effect stacks when it is copied.
- How any once-per-turn, once-per-roll, or once-per-round limits behave.
- What UI feedback should appear on the original Joker slot and The Portrait slot.
